# Evidence Ledger

This directory stores structured, source-traceable evidence extracted during the review.

Planned datasets:

- `sources.csv` — bibliographic registry and screening status
- `algorithms.csv` — algorithm registry
- `algorithm_mechanisms.csv` — normalized mechanism features
- `benchmark_suites.csv` — suite properties
- `claims.csv` — claim-to-source ledger
- `comparisons.csv` — published comparison conditions
- `reproducibility.csv` — implementation/reproduction status
- `gaps.csv` — candidate and validated research gaps

Every consequential review claim should be traceable to one or more source records.
