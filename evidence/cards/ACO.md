# Ant Colony Optimization Evidence Card

## Mechanism
Distributed constructive search reinforces components through pheromone memory while evaporation limits persistence.

## Persistent issues
Recent survey literature still identifies premature convergence, scalability and real-time applicability as important challenges.

## Atlas question
Can pheromone concentration/entropy provide a transferable state indicator separating productive reinforcement from irreversible path lock-in?

## Scope warning
ACO is naturally strongest in combinatorial/constructive settings; comparisons against continuous optimizers require problem-appropriate representations and must not be forced into a single leaderboard.

Status: candidate mechanism question; existing max-min, restart, adaptive and hybrid remedies must be audited.
