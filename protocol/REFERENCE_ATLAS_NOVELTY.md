# Reference Atlas Novelty Contract

## Ambition
The atlas is designed as a durable researcher reference, not as a claim that no prior optimization review exists.

## Prior-art boundary
Existing reviews already cover large algorithm catalogues, taxonomies, benchmark functions, structural bias, structural similarity, applications, and performance analysis. Therefore none of those alone is claimed as the novelty.

## Proposed integrated contribution
The atlas links, at cell level:

algorithm identity
→ mechanism ancestry
→ mechanism/DNA
→ problem-property exposure
→ evidence status
→ confidence
→ reproducibility
→ structural similarity
→ documented failure
→ experimentally observed failure frontier
→ unresolved gap
→ exact resolving experiment
→ comparator recommendation

The key unit is not an algorithm paragraph. It is a traceable **algorithm × condition × evidence** record.

## Researcher utility test
A researcher should be able to use the atlas to answer:
1. What is the closest prior mechanism to my proposed method?
2. Which canonical and strong comparators should I include?
3. Which conditions have already been tested?
4. Which claimed strengths have independent evidence?
5. Where is evidence contradictory?
6. Which benchmark properties are missing?
7. Is the proposed novelty structurally redundant?
8. What known failure regimes exist?
9. Which existing remedies must be tested first?
10. What minimum experiment can establish or reject my proposed gap?

## Paper novelty claim allowed only after evidence freeze
The final novelty statement must be based on a documented closest-review comparison table. Never use unsupported phrases such as "first ever" or "no review has done this."

## Durable-reference design
The paper is a concise synthesis. The repository is the living evidence layer. Stable release snapshots provide citable versions.
