# Gap Validation Rules

A literature omission is not automatically a scientific gap.

## Gap levels

- G0 — Mentioned absence: future work is suggested; insufficient by itself.
- G1 — Evidence absence: systematic search finds no adequate evidence for a defined algorithm × condition question.
- G2 — Evidence conflict: comparable studies report materially inconsistent conclusions.
- G3 — Failure boundary: controlled experiments demonstrate a repeatable regime transition or failure.
- G4 — Mechanistic gap: failure is linked to a testable property of the algorithmic mechanism.
- G5 — Repair opportunity: established remedies do not adequately resolve the mechanism-level failure under fair tests.

Only G4–G5 should normally motivate a new algorithmic mechanism.

## Novelty firewall

Before proposing a new mechanism:
- search closest mechanisms, not just algorithm names;
- test established adaptations;
- compare computational and evaluation cost;
- rule out tuning-only explanations;
- test parent algorithm with and without the proposed component;
- validate on conditions not used to discover the mechanism.

## Evidence states

Use only DOCUMENTED, PARTIAL, CONTRADICTORY, UNTESTED, or PROJECT-VALIDATED.

Never silently convert UNTESTED into FAILED.
