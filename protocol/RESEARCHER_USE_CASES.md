# Researcher Use Cases

## Designing a new optimizer
Query nearest mechanisms → inspect structural similarity → inspect unresolved cells → identify existing remedies → select comparator set → predeclare resolving experiment.

## Selecting an optimizer for an application
Describe problem properties → retrieve algorithms with documented evidence in matching cells → inspect confidence/reproducibility → avoid extrapolating from unrelated benchmarks.

## Reviewing a manuscript
Map claimed novelty to mechanism ancestry → check nearest prior mechanisms → check comparator adequacy → check whether benchmark properties support the claimed scope.

## Building a benchmark study
Start from under-covered condition cells rather than repeatedly evaluating the same easy functions.

## Teaching optimization
Use the Mechanism River and DNA map to teach how information and search dynamics evolved instead of memorizing hundreds of metaphor names.

## Reproducing a result
Follow source → implementation → configuration → raw result → generated artifact provenance.
