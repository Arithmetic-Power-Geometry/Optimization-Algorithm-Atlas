# Research Agents

Agents are audit roles, not autonomous authorities. Every extracted claim remains source-traceable and is subject to cross-checking.

## Algorithm agents

One agent focuses on a canonical algorithm or tightly defined family and completes the standard algorithm evidence record.

Initial core set will include representative methods from:
- Nelder–Mead / pattern-search family;
- BFGS / L-BFGS;
- CMA-ES;
- genetic algorithms;
- differential evolution;
- SHADE / L-SHADE family;
- particle swarm optimization;
- ant-colony methods;
- estimation-of-distribution algorithms;
- Bayesian optimization;
- NSGA-II / NSGA-III;
- MOEA/D;
- representative constraint-handling and dynamic-optimization methods.

## Cross-cutting agents

- structural bias;
- structural similarity/redundancy;
- benchmark coverage;
- scalability;
- noise/robustness;
- constraints;
- mixed variables;
- dynamics;
- hyperparameter sensitivity;
- initialization;
- computational cost;
- statistics;
- reproducibility;
- real-world evidence.

## Agent output rule

Each agent returns:
1. sourced facts;
2. unresolved/contradictory evidence;
3. candidate gaps;
4. proposed resolving experiments.

Agents do not declare an algorithm universally superior.
