# Uniform Algorithm Agent Protocol

Every algorithm agent performs the same audit to prevent selective evidence extraction.

## A. Identity and provenance
Find the canonical paper, bibliographic identifiers, first algorithm definition, aliases, and reliable implementation sources.

## B. Mechanism reconstruction
Describe the algorithm without metaphor: state, representation, initialization, information used per update, search operator, selection/replacement, memory, adaptation, boundary/constraint handling, diversity/restart, termination.

## C. Mechanism ancestry
Identify earlier algorithms containing materially similar operators. Record inherited, modified, and genuinely new components.

## D. Theory
Extract convergence results, assumptions, invariances, complexity, guarantees, counterexamples, and theoretical limitations. Never infer a guarantee from empirical success.

## E. Published empirical evidence
For each substantial comparison record benchmark, dimension, evaluation budget, independent runs, initialization, parameter policy, competitors, metrics, statistical procedure, and reported result.

## F. Negative evidence
Actively search for failure, stagnation, structural bias, poor scaling, sensitivity, contradictory replication, and regimes where claimed advantages disappear.

## G. Reproducibility
Check code availability, pseudocode/code consistency where inspectable, parameter/seed/budget specification, and independent reproduction.

## H. Coverage vector
Mark evidence as established, partial, contradictory, or absent for low/high dimension; separable/nonseparable; unimodal/multimodal; ill-conditioned; noisy; constrained; dynamic; mixed-variable; expensive-objective; and real-world regimes.

## I. Candidate gaps
A gap is accepted only if the agent states what evidence exists, exactly what remains unknown, why it matters, and the experiment or theorem that could resolve it.

## J. No universal superiority language
Finite benchmark outcomes remain conditional evidence.

## Cross-check
A cross-cutting gap audit must independently check each candidate before it becomes a validated project gap.
