# Benchmark Property Mapping

Publication interpretation is organized by problem properties rather than isolated function IDs.

## Continuous BBOB dimensions
For each selected BBOB function, the evidence table will retain its benchmark group/property annotations (for example separability, conditioning, modality and global structure) from authoritative suite documentation.

## Noise
Noisy-suite results are analyzed separately from noiseless results. Noise is not treated as another pooled function.

## Discrete
IOH PBO results constitute a distinct evidence domain. They test discrete/pseudo-Boolean mechanisms and are not directly averaged with continuous BBOB outcomes.

## Dimension and budget
Dimension and evaluation budget are explicit axes, never nuisance metadata.

## Publication rule
Function-level results remain available in supplementary artifacts, while the main paper synthesizes property-conditioned patterns only when the mapping and within-group evidence support that aggregation.
