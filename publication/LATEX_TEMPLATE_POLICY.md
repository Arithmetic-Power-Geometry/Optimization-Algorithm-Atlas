# IEEE/TEVC LaTeX Template Policy

The paper source is created only after P031 Evidence Freeze.

## Preferred source
At drafting time, obtain the then-current official IEEE journal LaTeX template through the IEEE Author Center / IEEE Template Selector and select IEEE Transactions on Evolutionary Computation when the final venue decision is TEVC.

If the authors provide an official TEVC template ZIP, preserve that package as the local authoritative template for the submission build.

## Rules
- do not freeze today's template months before submission;
- do not use unofficial third-party style files when an official IEEE source is available;
- do not modify IEEEtran class files merely to force layout;
- keep scientific content separate from template/style infrastructure;
- compile and validate the final LaTeX package before submission;
- run reference, PDF and LaTeX validation appropriate to IEEE submission;
- update template only through a controlled pre-submission migration if IEEE changes requirements.

## Drafting
Scientific sections are drafted from frozen evidence first and then placed into the official IEEE source package. Template formatting never determines or alters scientific claims.
