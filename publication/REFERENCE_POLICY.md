# Reference Policy

## Source hierarchy
1. Original/canonical algorithm paper.
2. Primary theoretical or empirical study for a specific claim.
3. Independent replication/counterevidence.
4. Systematic/critical review for synthesis and search expansion.
5. Benchmark/software primary documentation.

## Rules
- Never cite a secondary review for an original algorithm definition when the primary paper is available.
- Verify title, authors, year, venue and DOI before evidence freeze.
- Do not infer a claim from an abstract beyond what the abstract supports.
- Store experimental conditions with empirical claims.
- Preserve contradictory sources.
- Mark preprints distinctly from peer-reviewed sources.
- Do not use citation count as evidence quality.
- Do not create references from model memory.
- Every final reference must resolve to a verified bibliographic record.
- Retracted/corrected work must be explicitly flagged.

## Final audit
Before submission, validate all DOI/metadata pairs and every in-text claim-to-reference link.
