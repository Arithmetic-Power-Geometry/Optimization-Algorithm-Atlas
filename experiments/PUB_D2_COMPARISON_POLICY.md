# PUB-D2 Comparison Policy

PUB-D2 is the first complete dimensional layer of PUBBBOB001.

Current comparison artifacts are descriptive and remain RUN_COMPLETE_UNVERIFIED. Objective values are summarized within function and checkpoint. They are not averaged across heterogeneous BBOB functions to create an overall winner.

Cross-function performance claims require the separately frozen target-attainment protocol. The intended stronger analysis uses target attainment, evaluations-to-target, ECDF/anytime views, paired condition-level contrasts, failure/termination reporting, and runtime/overhead as a separate axis.

Ranks, if later reported, are descriptive only and cannot replace effect magnitude, uncertainty, or condition-level evidence.
