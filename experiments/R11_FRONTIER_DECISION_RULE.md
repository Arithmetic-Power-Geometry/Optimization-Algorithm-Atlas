# R11 Frontier Decision Rule

This rule is fixed before interpreting held-out confirmation outcomes.

A candidate failure frontier requires all of the following:
1. A target-attainment reliability transition across ordered dimension/budget conditions, not merely a change in median objective value.
2. The transition must be visible in COCO-authoritative target-runtime evidence.
3. Discovery evidence uses instances 1–5 only.
4. Confirmation evidence uses held-out instances 6–10 only.
5. Direction of the transition must reproduce on held-out instances.
6. Boundary uncertainty must be reported; a single exact dimension is not claimed when evidence only brackets a transition.
7. Algorithm-wide or universal-failure language is prohibited; conclusions are limited to the evaluated BBOB conditions and frozen configurations.
8. A G4/G5 repair opportunity is declared only when the reproduced failure has a plausible mechanism-level explanation supported independently by the mechanism/literature evidence. Performance deterioration alone is insufficient.

R12 is WARRANTED only if item 8 is satisfied. Otherwise R12 is NOT_WARRANTED for the present paper and the observed frontier remains a characterization result rather than motivation for an invented remedy.
